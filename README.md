### What I work on
- **Systematic strategy research**: signal design, backtesting, rolling out-of-sample validation
- **Options research**: short volatility structures, volatility filters, position sizing
- **Momentum & relative strength**: custom RS screener adapted from the JdK RS-Ratio/Momentum method
- **Risk**: portfolio drawdown analysis and Monte Carlo simulation
- **Machine learning in finance**: language-model based return prediction on Indian equities
